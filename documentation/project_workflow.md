**E-COMMERCE SQL DATA ANALYSIS PROJECT WORKFLOW**

**PROJECT OVERVIEW**

This project analyses the e-commerce dataset to identify business insights related to customer behaviour, sales performance, seller performance, product categories, payment trends, customer satisfaction and delivery operations. 
These analysis are performed using SQL for data extraction, data transformation, data exploration, data cleaning followed by reporting of key metrics.

**BUSINESS OBJECTIVE**

The primary objective of this project is to use transactional e-commerce data to answer critical business questions and generate actionable insights.

Key focus areas include: 

1. Revenue and Sales Performance
2. Customer acquisition and retention
3. Product Category Performance
4. Seller Performance Evaluation
5. Payment Behavior Analysis
6. Customer Review Analysis
7. Delivery and Logistics Performance
