**E-Commerce SQL Data Analysis Project Workflow**

**Project Overview**

This project analyzes the e-commerce dataset to indentify business insights related to customer behavior, sales performance, seller performance, product categories, payment trends, customer satisfaction and delivery operations. These analysis are performed using SQL for data extraction, data transformation, data exploration, data cleaning followed by reporting of key metrics.


**Business Objective**

The primary objective of this project is to use transactional e-commerece data to answer critical business questions and generate actionable insights.
